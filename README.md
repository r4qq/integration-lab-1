# Integracja systemów informatyczneych - lab1
testlocal
testgithub

**Celem laboratorium jest panowanie systemu kontroli wersji Git, platformy GitHub oraz przygotowanie lokalnego środowiska programistycznego (Django)** 

**Wymagania ogólne:** 

* zainstalowane narzędzie kotroli wersji git
* zainstalowany interpreter języka python
* skonfigurowane konto Github
* uwierzytelnienie użytkownika Github (gh auth)
* utworzone repozytorium projektu
 

**uruchomienie projektu django**
```bash
python backend/manage.py runserver
```
